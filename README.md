# Business Card Project

This project is a simple HTML and CSS implementation of a business card. It is designed to showcase basic web development skills and styling techniques.

## Project Structure

- **index.html**: Contains the HTML structure of the business card.
- **style.css**: Contains the CSS styles for the business card.

## How to Use

1. Open the `index.html` file in any modern web browser to view the business card.
2. Modify the `style.css` file to customize the design as needed.

## Features

- Responsive design.
- Clean and modern layout.
